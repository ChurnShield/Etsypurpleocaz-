## The Wealth Model — How This Actually Makes Money

### Single Product Economics
- Price: £2.99
- Etsy fees (6.5% transaction + £0.18 listing): ~£0.40
- Net per sale: ~£2.59
- Break even on pipeline time at: 4 sales per listing

### Bundle Economics (the real opportunity)
- Price: £29.99
- Etsy fees: ~£2.15
- Net per bundle sale: ~£27.84
- One bundle sale = 10× a single product sale
- Bundle converts better because perceived value is higher

### The Compounding Mechanism
More listings → more Etsy search surface area → more organic traffic
More sales → more reviews → higher search ranking → more sales
More data → better titles and thumbnails → higher conversion rate
Better conversion rate → more revenue from same traffic

This is why catalogue depth matters more than individual listing quality.

## Traffic Strategy — How Listings Become Revenue

Building listings without traffic is pointless.
Three traffic channels, all compounding:

### Channel 1: Etsy Organic (primary)
- Keyword-optimised titles and tags (learning loops improve this)
- Catalogue depth — more listings = more search surface area
- Reviews accumulate over time — older listings rank higher
- External traffic signals boost Etsy algorithm ranking

### Channel 2: Pinterest (free, evergreen)
- Every listing image becomes a Pinterest pin
- Pinterest pins drive traffic for months after posting
- Pin once → traffic forever → Etsy algorithm reward
- Build this into the pipeline: listing built → auto-pin

### Channel 3: Twitter/X Build in Public (brand + traffic)
- @churnshield documents the building process
- Attracts other sellers, entrepreneurs, AI enthusiasts
- Drives direct traffic to Etsy shop
- Builds audience that becomes future customers and advocates
- Every listing launch = a Twitter thread

## The 3 Learning Loops

### Loop 1: Weekly Sales Feedback (building next)
Every Monday 8am — automated performance check:
- Views, favourites, conversions for every listing
- Flag underperformers (10+ views, zero sales in 2 weeks)
- Extract patterns from top performers → winning_playbook.md
- Next listing built against proven patterns not assumptions

### Loop 2: Self-Improving Pipeline
Every sub-agent failure → auto-appends to skill gotchas
Every success → logs winning pattern to skill file
System improves every run. No human required.

### Loop 3: Cross-Listing Intelligence
937 existing listings contain the answer to what works.
One agent analyses them all — title structure, thumbnail style,
price, tags, conversion rates.
Winning patterns become the new baseline for every future listing.
